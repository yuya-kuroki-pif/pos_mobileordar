# dinii との機能差分

dinii（株式会社ダイニー）の公開情報をもとに、このシステムとの差分を整理したもの。
「dinii と同じ仕様にする」という目標を、実行可能な単位に分解するための土台。

出典は dinii の公開サイト（[dinii.jp](https://dinii.jp/)、
[POSレジ](https://dinii.jp/service/pos-register/)、
[モバイルオーダー](https://dinii.jp/service/mobile-order/)）。
**非公開の仕様・画面設計・内部実装は含まない。** ここに書いてあるのは
「外から見える機能の名前」までで、実際の挙動の細部は推測になる。

## 前提

dinii は 8 つのプロダクトの集合体で、このシステムが今カバーしているのは
そのうち 2 つの一部分。全体像は次のとおり。

| # | dinii のプロダクト | 現状 |
| --- | --- | --- |
| 1 | POS レジ | △ 中核はあるが機能差が大きい |
| 2 | モバイルオーダー | △ 中核はあるが機能差が大きい |
| 3 | 顧客管理（CRM） | ✗ 未着手 |
| 4 | 勤怠管理 | ✗ 未着手 |
| 5 | モバイル決済（セルフ決済） | ✗ 未着手 |
| 6 | キャッシュレス決済 | ✗ 未着手 |
| 7 | 予約台帳 | ✗ 未着手 |
| 8 | 経営管理（日次 PL・原価・人件費） | ✗ 未着手 |

## 外部契約が必要で、コードだけでは完結しないもの

以下は実装以前に、事業者としての契約・審査が必要になる。

- **LINE ミニアプリ / 自動会員化** — LINE 公式アカウントと LINE ミニアプリの
  審査・契約が要る。dinii の CRM はここが土台なので、これ抜きに
  「同じ」にはならない。
- **キャッシュレス決済** — 決済代行会社との加盟店契約が必要。
  手数料率も契約次第。現状の会計は「どの手段で払ったかの記録」に留めている。
- **レシートプリンタ・キャッシュドロア** — 対応機種の選定と調達。

## この文書の扱い

dinii の機能は更新され続けている（同社は年 44 回のバージョンアップを公表している）。
ここに書いた差分は **2026-09-19 時点の公開情報** に基づくもので、
実際の dinii の挙動と細部で食い違う可能性がある。

正確な差分が必要な場合は、実際の dinii ダッシュボードの画面を確認したうえで
この表を更新すること。
